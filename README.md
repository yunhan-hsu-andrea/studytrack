# StudyTrack

### StudyTrack is a Python command-line application that helps students track and manage their study sessions. Users can add, edit, delete, and analyze study sessions using a simple menu-driven interface. The application stores data using SQLite and supports exporting study data to CSV files.

## Features
- Add study sessions
- View all study sessions
- Search sessions by ID
- Edit existing sessions
- Delete study sessions
- Track mood and focus level
- Analyze study habits
- Export study sessions to CSV
- SQLite database storage

## Installation
- Clone the repository:  
git clone https://github.com/your-username/studytrack.git  
- Navigate into the project folder:  
cd studytrack  
- Run the application:  
python main.py  

## How It Works

When the program starts, users are shown a menu:
1. Add study session
2. View all sessions
3. Find session by ID
4. View analytics
5. Edit a session
6. Delete a session
7. Export all sessions to CSV
8. Exit

Users can track:
- Subject
- Study date
- Study time
- Duration
- Mood
- Focus level
- Analytics

StudyTrack provides analytics such as:
- Total study time
- Average focus level
- Average session duration
- Most studied subject
- Study time by subject
- Session count by subject
